# 🌟 About the Project

**AI-Powered Student Hub** is a modern student collaboration platform designed to make academic support more accessible, interactive, and community-driven.

Instead of studying alone, students can **connect with other students, exchange knowledge, find study partners, ask questions, book focused sessions, and track their contribution** within one platform.

The goal is simple:

> **Connect students with the right people, the right knowledge, and the right help at the right time.**

---

# 🎯 Why Student Hub?

Students often have questions but don't always know **who to ask**.

Student Hub brings students together based on what they can **teach** and what they want to **learn**.

# 🚀 Getting Started

## Prerequisites

Make sure you have installed:

* Node.js
* npm
* Git

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/ai-student-hub.git

cd ai-student-hub

npm install
```

## Run Development Server

```bash
npm run dev
```

Open the URL displayed in your terminal.
